# Abiogenesis — Abhay Bhat

This is the editable portfolio: plain HTML, CSS and JavaScript, with text stored in JSON and actual image/PDF files.

## Where things live

| File or folder                       | What's in there?                                               |
| ------------------------------------ | ------------------------------------------------------------------ |
| `index.html`                         | Shared header, footer, navigation     |
| `content/site.json`                  | Homepage introduction, framing, email, LinkedIn and résumé path    |
| `content/cases/chemomicrobiome.json` | ChemoMicrobiome case study                                         |
| `content/cases/diagnostics.json`     | Medical-device customer-discovery case study                       |
| `content/cases/moietymapper.json`    | MoietyMapper case study and code walkthrough                       |
| `content/cases/glp1.json`            | GLP-1 case study                                                   |
| `content/cases/index.json`           | Which case studies appear, and their order                         |
| `content/projects.json`              | Other projects, teams and topic tags                               |
| `content/profile.json`               | Education, courses, experience, publications and institution links |
| `content/abiogenesis.json`           | Your original Abiogenesis essay, preserved verbatim                |
| `content/icorps-timeline.json`       | Presentation sequence and what changed between versions            |
| `content/presentations.json`         | Deck titles, ordered slide images and PDF paths                    |
| `styles/`                            | Colours, fonts, sizes, spacing and responsive layout               |
| `scripts/pages/`                     | A separate layout file for each page/view                          |
| `scripts/components.js`              | Shared topic chips, links, tabs, figures and presentation cards    |
| `scripts/theme.js`                   | Theme switching and saved preference                               |
| `scripts/router.js`                  | Which page each URL opens                                          |
| `assets/`                            | Images, logos, fonts, PDFs and the goose icon                      |
